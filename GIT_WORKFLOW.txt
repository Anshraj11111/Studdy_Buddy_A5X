COLLABORATOR KA KAAM (Usse yeh bhej do)
================================================================

PEHLI BAAR SETUP (sirf ek baar karna hai):
------------------------------------------

1. Repo clone karo:
   git clone https://github.com/AnshrajBaghel/Studdy_Buddy_A5x.git
   cd Studdy_Buddy_A5x

2. Dependencies install karo:
   cd frontend
   npm install
   cd ../backend
   npm install

3. Backend .env file — Anshraj se separately maango (WhatsApp pe)
   File milne ke baad: backend folder mein .env naam se save karo

4. Local run karo:
   Backend:  cd backend  → npm run dev   (port 5000)
   Frontend: cd frontend → npm run dev   (port 3000)


DAILY WORKFLOW (har baar kaam karne se pehle):
-----------------------------------------------

STEP 1 — Latest code lo:
   git checkout main
   git pull origin main

STEP 2 — Apna branch banao:
   git checkout -b feature/jo-kaam-karna-hai
   
   Examples:
   git checkout -b feature/login-page-fix
   git checkout -b feature/dashboard-update
   git checkout -b feature/navbar-mobile-fix
   git checkout -b hotfix/urgent-bug-fix

STEP 3 — Kaam karo (files edit karo)

STEP 4 — Local test karo (zaroor karo deploy se pehle)

STEP 5 — Changes save karo:
   git add .
   git commit -m "fix: kya kiya iska short description"

   Commit message examples:
   git commit -m "fix: login page mobile responsive"
   git commit -m "feat: dark mode add kiya dashboard pe"
   git commit -m "fix: navbar notification dropdown fix"

STEP 6 — Push karo:
   git push origin feature/jo-kaam-karna-hai

STEP 7 — GitHub pe jao:
   - Repository kholo
   - "Compare & pull request" button dikhega
   - Title aur description likho kya kiya
   - "Create pull request" karo
   - Anshraj review karke merge karega


BRANCH NAMING RULES:
--------------------
   feature/kaam-ka-naam    → naya feature ya fix
   hotfix/bug-ka-naam      → urgent production bug

IMPORTANT RULES:
----------------
   - KABHI seedha main branch pe push mat karo
   - Har naye kaam ke liye NAYA branch banao
   - .env file kabhi commit mat karo
   - PR banane se pehle local pe test zaroor karo
   - Kaam khatam hone ke baad purana branch delete kar sakte ho:
     git branch -d feature/jo-kaam-karna-tha

JAB COLLABORATOR KA PR AAYE:
------------------------------

1. GitHub pe notification aayegi
2. Repository → "Pull requests" tab pe jao
3. PR kholo → Files changed dekho
4. Sab theek lage toh "Merge pull request" karo
5. Vercel automatically deploy kar dega

JAB SEEDHA KUCH FIX KARNA HO TU KHUD:
----------------------------------------

   git checkout main
   git pull origin main
   git checkout -b fix/jo-fix-karna-hai
   
   --- kaam karo ---
   
   git add .
   git commit -m "fix: kya fix kiya"
   git push origin fix/jo-fix-karna-hai
   
   GitHub pe PR banao aur merge karo
   (ya directly main pe push kar sakta hai tu — owner hai)

------------------------

================================================================
GITHUB PE PROTECTION RULE SET KARO (ek baar):
================================================================

1. GitHub repo → Settings → Branches
2. "Add branch ruleset" → Name: main-protection
3. Target: main branch
4. "Require a pull request before merging" — ON karo
5. Save karo

Isse koi bhi directly main pe push nahi kar sakta.
